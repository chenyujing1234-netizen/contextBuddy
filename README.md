# ContextBuddy

一个将各类**上下文数据**统一保存到本地的桌面应用。它把散落在浏览器、微信、个人电脑与手机端的上下文（浏览记录、聊天记录、AI 对话、操作记录等）集中收纳到本地文件夹，为后续的跨端同步、上下文管理与分享（WorkBuddy、第三方应用等）提供统一的数据底座。

> 当前阶段以**本地保存**为主，产品定位为免费工具，后续再做跨端同步与管理、企业端能力。

## 上下文数据类别

ContextBuddy 面向以下上下文来源进行采集与归档：

| 类别 | 说明 | 状态 |
| --- | --- | --- |
| 微信数据（个微） | 自动保存个人微信聊天数据，解密过程对用户透明、无需感知 | 已实现 |
| 浏览器记录 | 豆包、Qwen 等 AI 平台的对话记录，通过浏览器插件采集 | 已实现 |
| 电脑操作记录 | 采集本机操作记录 | 规划中 |
| 手机端手动上传 | 配合 Nextcloud 等手机端 App 手动上传 | 规划中 |
| 定制浏览器数据 | 通过自动编写的浏览器插件抓取定制浏览器上的数据 | 规划中 |

## 主要功能

- **微信数据自动保存**：后台常驻线程周期性解密微信数据库，生成结构化数据（JSON / TXT），支持自定义保存路径与归档类型（结构化数据 / 数据库文件）。
- **浏览器记录**：一键检测、安装并引导配置「AI 对话导出」浏览器插件；从服务端拉取本机 device 上传的 GPT 对话，支持会话列表展示与 Markdown 下载（单会话 / 多会话 zip）。
- **聊天记录分类工具**：对导出的微信聊天内容按人物自动分类归档（LLM 判定归属人），支持人工确认、目录推荐与手工微调。
- **GPT 对话查看 / 分类工具**：拉取服务端 GPT 对话数据并在本机查看、标注、统计。

## 技术栈

- **后端**：Python 3.11+ / FastAPI（默认端口 `10392`）
- **前端**：Vue.js / Nuxt
- **桌面端**：Electron
- **打包**：electron-builder（Windows NSIS / macOS DMG、ZIP）

## 快速开始

### 一键启动（推荐）

```bat
start_app.bat
```

会依次启动前端（`:3000`）、后端（`:10392`）与 Electron 窗口。

### 从源码运行

```bash
# 1) 安装后端依赖
uv sync --no-editable

# 2) 安装桌面端依赖
cd desktop && npm ci && cd ..

# 3) 安装前端依赖
cd frontend && npm ci && cd ..

# 4) 启动完整桌面开发模式
cd desktop && npm run dev
```

访问：

- 前端界面：http://localhost:3000
- API 服务：http://localhost:10392
- API 文档：http://localhost:10392/docs

## 配置文件与日志

- 配置目录：`%APPDATA%\ContextBuddy\`（微信数据 manifest 位于 `contexts\wechat\manifest.json`）
- 日志目录：`%APPDATA%\ContextBuddy\output\logs\`
