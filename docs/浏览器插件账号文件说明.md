# 浏览器插件账号文件说明（供浏览器开发方对接）

本文说明 ContextBuddy 桌面端登录后，把「手机号」写到浏览器插件安装目录下的哪个文件、什么格式，
以及插件应当如何读取并在上传数据时携带手机号。

## 1. 账号文件位置

ContextBuddy 后端在用户登录成功后，会向「浏览器插件安装目录」写入一个 `account.json` 文件。
该目录即桌面上「安装插件」时提示加载扩展所选择的目录（内有 `manifest.json` 的那一层）。

- Chrome / Edge 扩展根目录：

  ```
  <数据目录>/browser_history/extension/account.json
  ```

- Firefox 扩充组件子目录：

  ```
  <数据目录>/browser_history/extension/firefox/account.json
  ```

其中 `<数据目录>` 由环境变量 `WECHAT_TOOL_DATA_DIR` 决定：

- 桌面版（Electron）默认指向用户数据目录，例如 Windows 下 `%APPDATA%\WeChatDataAnalysis`；
- 开发环境未设置该变量时，回退到程序启动的工作目录（仓库根目录）。

> 结论：`account.json` 与 `manifest.json` 在**同一目录**。插件侧优先通过
> `chrome.runtime.getURL('account.json')` / `browser.runtime.getURL('account.json')`
> 读取，无需拼接绝对路径。

## 2. 文件格式

`account.json` 为 UTF-8 编码的 JSON，结构固定如下：

```json
{
  "phone": "13800138000"
}
```

字段说明：

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `phone` | string | 已登录账号的手机号（11 位，`1[3-9]xxxxxxxxx`） |

备注：

- 未登录时，该文件**不存在**（后台会删除）；
- 退出登录时，应用会同时删除 `account.json`（Chrome 与 Firefox 两份都会删除）；
- 若文件存在但 `phone` 为空字符串，视为未登录。

## 3. 插件读取方式

以 Chrome（Manifest V3）为例，插件在后台/内容脚本中读取本扩展自身文件：

```js
async function readPhone() {
  try {
    const res = await fetch(chrome.runtime.getURL('account.json'));
    if (!res.ok) return '';
    const data = await res.json();
    return String(data && data.phone || '');
  } catch (e) {
    return '';
  }
}
```

Firefox（WebExtension）同理，把 `chrome` 换成 `browser`（或保持 `chrome` 兼容写法）。

## 4. 上传时携带手机号

插件的上传请求（当前为 `POST /upload`，协议见 `content.js` 中 `UPLOAD_SERVER`）需要新增携带手机号，
字段名统一用 **`phone`**，放在请求体 JSON 顶层，例如：

```json
{
  "platform": "deepseek",
  "conversation_id": "xxx",
  "title": "xxx",
  "conversation": [ ... ],
  "device_id": "xxx",
  "phone": "13800138000"
}
```

> `phone` 的值直接取上一步 `readPhone()` 的结果；取不到（未登录 / 文件不存在）时，
> 可传空字符串或省略该字段，但**已登录后所有上传都应带上手机号**，供后续服务端按账号归集数据。

## 5. 一致性校验（可选）

插件触发上传前可先校验：若 `account.json` 中的 `phone` 与上一次缓存不同，说明账号已切换，
建议以最新读取到的 `phone` 为准。

---

### 附录：应用自身登录态文件（非插件侧，仅供参考）

除插件目录的 `account.json` 外，ContextBuddy 后端还会在
`<数据目录>/account.json` 保存应用自身的登录态，结构为：

```json
{
  "phone": "13800138000",
  "logged_in_at": "2026-10-30T17:00:00"
}
```

该文件由桌面端/后端维护，浏览器插件无需也不应读取它；插件只读取上文第 1、2 节所述扩展目录内的
`account.json`。
